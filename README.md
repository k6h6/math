# أدوات الرياضيات التفاعلية

موقع عربي ثابت (Static) يوفّر أداتين تعليميتين تفاعليتين تعملان مباشرة في المتصفح، مناسبتان للطلاب والمعلمين وأولياء الأمور. لا يحتاج الموقع إلى خادم أو قاعدة بيانات أو عملية بناء (Build).

## الأدوات

### 1. أبطال جدول الضرب — `multiplication-heroes.html`

لعبة تفاعلية لتعلّم وحفظ جدول الضرب (1–12):

- اختيار جدول محدد أو «تحدي جميع الجداول الشامل» (أرقام عشوائية من 2–11 × 1–12).
- 10 أسئلة في الجولة مع خيارات متعددة ومؤقّت 15 ثانية لكل سؤال.
- نظام نجوم (+2 لكل إجابة صحيحة، +5 مكافأة عند 80% فأعلى)، وسلسلة إجابات (Streak)، ونجوم محفوظة محلياً في `localStorage`.
- «الأسئلة التحفيزية والألغاز»: اختبار من 5 أسئلة تجمع الرياضيات بالتفكير الإيجابي.
- مؤثرات صوتية (Tone.js) وألعاب confetti وخلفية جسيمات متحركة (يمكن إيقاف الصوت من الزر العلوي).

### 2. مغامرة الأعداد والمنازل — `place-value-adventure.html`

أداة وألعاب لتعلّم القيمة المنزلية للأعداد حتى 999,999 (مناسب للصف الرابع الابتدائي):

- **مختبر الأعداد**: أدخل عدداً (يدعم الأرقام العربية ٠–٩ والإنجليزية 0–9) أو استخدم أزرار +/- لتعديل كل منزلة، وشاهد الصيغة القياسية والتحليلية واللفظية (مع نطق صوتي).
- **صائد القيمة المنزلية**: حدد قيمة الرقم الملوّن في عدد من 6 خانات.
- **باني الصيغة التحليلية**: اختر بطاقات القيم المنزلية لتكوين العدد المطلوب (انقر بطاقة مختارة لإزالتها).
- **تحدي السرعة**: 45 ثانية من أسئلة متنوعة (قيمة منزلية / صيغة تحليلية / تحويل من اللفظي).
- نظام نقاط ونجوم داخل الجلسة، ومؤثرات صوتية.

```

├── multiplication-heroes.html     # أداة جدول الضرب
├── place-value-adventure.html     # أداة القيمة المنزلية
├── 404.html                       # صفحة خطأ مخصصة لـ GitHub Pages
├── assets/
│   └── images/
│       └── favicon.svg            # أيقونة الموقع
├── README.md

```

جميع المسارات نسبية (`assets/images/favicon.svg`) لتعمل الموقع بشكل صحيح تحت رابط مستودع GitHub Pages مثل `https://USERNAME.github.io/REPOSITORY/`.

## التشغيل المحلي

لا حاجة لأي أدوات. افتح `index.html` مباشرة في المتصفح، أو (موصى به لتجربة شروط النشر) شغّل خادماً محلياً بسيطاً:

```bash
# بايثون
python -m http.server 8000
# ثم افتح http://localhost:8000/
```

```bash
# أو باستخدام Node (npx)
npx serve .
```

> ملاحظة: يعمل الأداتان عند فتح الملف مباشرة (`file://`) أيضاً، لكن الخادم المحلي أدق لمحاكاة بيئة GitHub Pages.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub وارفع الملفات:

```bash
git init
git add .
git commit -m "Add interactive math tools site"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

2. من صفحة المستودع على GitHub: **Settings → Pages**.
3. تحت **Build and deployment** اختر:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` و مجلد `/ (root)`
4. اضغط **Save**. بعد دقيقة أو دقيقتين يصبح الموقع متاحاً على:

```
https://USERNAME.github.io/REPOSITORY/
```

لا توجد خطوة بناء (Build) ولا ملفات يجب استثناؤها — الموقع ثابت بالكامل.

### نشر عبر GitHub Actions (اختياري)

يمكن도 نشره تلقائياً بأكشن رفع الصفحة، لكنه غير ضروري هنا. إن رغبتَ بذلك لاحقاً أضف `.github/workflows/pages.yml` باختيار `actions/upload-pages-artifact` لمجلد المشروع و`actions/deploy-pages`.

## ربط نطاق خاص لاحقاً (Custom Domain)

الفرق بين النوعين:

| النوع | مثال | ملاحظات |
|---|---|---|
| رابط GitHub Pages | `https://USERNAME.github.io/REPOSITORY/` | جاهز فور تفعيل Pages؛ يحتوي الموقع على مسار فرعي `REPOSITORY` ولهذا كل المسارات في المشروع نسبية. |
| نطاق خاص | `https://tools.example.com/` | يُدار من إعدادات GitHub Pages + سجلات DNS عند مزوّد النطاق. |

### خطوات ربط النطاق لاحقاً

1. أنشئ ملف `CNAME` في جذر المستودع يحتوي على النطاق فقط (بدون `https://` ولا مسار):

```
tools.example.com
```

2. من **Settings → Pages** فعّل الخيار **Enforce HTTPS** بعد اكتمال الربط.
3. أضف سجلات DNS عند مزوّد النطاق:

**لنطاق فرعي** (مثل `tools.example.com`) — سجل A أو CNAME:

- `CNAME` → `USERNAME.github.io` (الأبسط)، أو
- سجلات A للـ apex عند الاستضافة الفرعية:

```
@  A  185.199.108.153
@  A  185.199.109.153
@  A  185.199.110.153
@  A  185.199.111.153
```

**للنطاق الرئيسي (Apex)** مثل `example.com`: استخدم سجلات A السابقة أو سجل `ALIAS`/`ANAME` (حسب المزوّد) إلى `USERNAME.github.io`.

بما أن كل الملفات هنا نسبية، سيعمل الموقع فوراً تحت أي نطاق أو مسار دون تعديل.

## الاعتماديات الخارجية

- Tailwind CSS (Play CDN) — للتنسيق.
- FontAwesome — للأيقونات.
- Google Fonts (Cairo / Tajawal) — الخطوط العربية.
- Tone.js — المؤثرات الصوتية.
- canvas-confetti — تأثير الاحتفال.

جميعها تُحمَّل من شبكات توزيع عامة (CDN). عند انقطاع الإنترنت تبقى الأدوات تعمل (حسابات وواجهة)، لكن تختفي الخطوط والأيقونات والمؤثرات الصوتية.

## ملاحظات وقيود معروفة

- **لا خادم مطلوب**: كل الحسابات تتم في المتصفح.
- **البيانات**: نجوم أداة جدول الضرب تُحفظ في `localStorage` (متصفح الجهاز فقط، وحدها). أما نقاط أداة القيمة المنزلية فتبقى ضمن الجلسة فقط ولا تُحفظ بعد إغلاق التبويب.
- **النطاق الصفي**: أداة القيمة المنزلية تدعم الأعداد حتى 999,999 (6 خانات) — هذا نطاق مقصود ومناسب للصف الرابع، وليس عيباً.
- **الأجهزة**: التخطيط متجاوب (جوال/لوحي/حاسوب). يُفضّل استخدام متصفح حديث.
- لا توجد إعلانات ولا تتبّع ولا جمع لأي بيانات شخصية.

## ترخيص الاستخدام

المحتوى التعليمي والبرمجي داخل هذا المستودع مخصص للاستخدام التعليمي. عدّل الأدوات بحرية لاحتياجاتك الصفية.
