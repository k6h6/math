# Math Adventures | مغامرات الرياضيات

منصة عربية ثابتة (Static) لتعلّم الرياضيات تعمل كاملةً في المتصفح: ألعاب تدريبية، تحدي يومي، أوراق عمل قابلة للطباعة، أوسمة إنجاز، وتقدّم محفوظ محلياً — بدون تسجيل ولا خادم ولا قاعدة بيانات.

الموقع المنشور: `https://k6h6.github.io/math/`

## الصفحات

| الصفحة | الملف | الوصف |
|---|---|---|
| الرئيسية | `index.html` | بطاقة تقدّم حيّة + المدخلات لكل الأدوات |
| أبطال جدول الضرب | `multiplication-heroes.html` | لعبة الضرب بخمسة أوضاع وأربعة مستويات |

## الألعاب

### أبطال جدول الضرب

- **4 مستويات**: سهل (8 أسئلة بلا مؤقّت)، متوسط (10 × 20ث)، صعب (12 × 15ث)، خبير (12 × 12ث حتى 15×12).
- **5 أوضاع**: تدريب تكيّفي (بلا مؤقّت، يرجّح الأسئلة التي أخطأت فيها)، تحدي الوقت، تحدي مختلط، تحدي الدقة (90% فأعلى = +5)، تحدي الزعيم (3 مراحل × 4 أسئلة، 8 صحيحة = +10 نجوم).
- **تدريب تكيّفي**: خريطة أوزان محدودة (≤150 مدخلاً) ترجّح الأزواج التي أخطأت فيها أكثر وتخفّض وزن ما أتقنته.
- **مراجعة الأخطاء**: بعد كل جولة تُعرض إجاباتك الخاطئة، ويمكنك جولة مراجعة إضافية (بدون نقاط).
- **النقاط**: +2 لكل صحيحة، +1 إضافية عند سلسلة ≥3، +5 لإكمال الجولة، +5 لدقّة ≥90% (10 إجابات فأكثر). أوسمة: بداية الرحلة، نجم الضرب، البرق، بطل الدقة، هزيمة الزعيم، كنز النجوم… إلخ.

### مغامرة الأعداد والمنازل

- **مختبر الأعداد** حتى 999,999: الصيغة القياسية والتحليلية واللفظية (مع نطق صوتي)، يقبل الأرقام العربية والإنجليزية.
- **لوحة تفصيل الرقم (جديد)**: اضغط أي رقم من خانات العدد لترى منزلته وقيمته ومساهمته في العدد.
- **3 ألعاب**: صائد القيمة المنزلية، باني الصيغة التحليلية، وتحدي السرعة (45 ثانية).
- **تحدي السرعة بـ6 أنواع أسئلة (جديد)**: القيمة المنزلية، الصيغة التحليلية، الصيغة اللفظية، الرقم الناقص، أكبر قيمة منزلية، اسم المنزلة.
- يعتمد مشتركاً على نظام التقدّم (نجوم وأوسمة محفوظة). تصميمه داكن ثابت (`data-force-theme="dark"`) بقرار تصميمي.

### تحدي اليوم

- 10 أسئلة من 5 أنواع (ضرب، قيمة منزلية، رقم مفقود، مقارنة، صيغة تحليلية) مولّدة بمولّد عشوائي **محصور بالتاريخ** — نفس الأسئلة لكل من يفتح الموقع في اليوم نفسه.
- نتيجة 7/10 فأكثر في أول إكمال = **+10 نجوم** (مرة واحدة يومياً)، مع أفضل نتيجة تُحفظ وتتابع سلسلة الأيام.

### أوراق العمل

- 4 أنواع أسئلة (ضرب، قيمة منزلية، أرقام مفقودة، مختلط) × 3 صعوبات × 10–30 سؤالاً.
- «رقم الورقة» يسمح بإعادة توليد الأسئلة نفسها بالضبط، مع مفتاح إجابات وتنسيق طباعة/PDF نظيف.

## التقدّم والبيانات

- مفتاحان فقط في `localStorage`: **`ma_progress`** (إحصائيات، أوسمة، تحدي اليوم، خريطة التدريب التكيّفي) و**`ma_settings`** (المظهر، الأرقام، الصوت، الحركة).
- ترحيل تلقائي من المفتاح القديم `math_stars`، وحماية من التخزين التالف أو المحجوب (يعمل بذاكرة مؤقتة عند الحاجة).
- «إعادة الضبط» في الإعدادات تلغي هذين المفتاحين فقط، ويمكن تنزيل نسخة احتياطية JSON قبل ذلك.
- لا حسابات، لا تتبّع، لا إرسال لأي بيانات — كل شيء داخل متصفحك.

## التشغيل المحلي

```bash
python -m http.server 8000   # ثم افتح http://localhost:8000/
```

أو افتح `index.html` مباشرة (`file://`) — يدعم العمل دون اتصال جزئياً.

## النشر على GitHub Pages

المستودع: `git@github.com:k6h6/math.git` — من صفحة المستودع: **Settings → Pages → Deploy from a branch → `main` / `(root)`**، ثم:

```
https://k6h6.github.io/math/
```

لا خطوة بناء ولا ملفات تُستثنى. ربط نطاق خاص لاحقاً يتطلب ملف `CNAME` + سجلات DNS عند المزوّد (لا يوجد نطاق مُشبع حالياً).

## الاعتماديات الخارجية

- **Tailwind CSS (Play CDN)** — في `place-value-adventure.html` فقط (واجهته مبنية عليه).
- **FontAwesome** — الأيقونات.
- **Google Fonts (Cairo / Tajawal)** — الخطوط العربية.
- **canvas-confetti** — تأثير الاحتفال.
- الصوت مبني على **Web Audio API أصلي** (لا Tone.js بعد الآن).

عند انقطاع الإنترنت تبقى الأدوات تعمل (حسابات وواجهة)، وتختفي الخطوط والأيقونات والاحتفالات.

## ملاحظات وقيود معروفة

- **نطاق الأعداد**: مغامرة الأعداد مقصودة حتى 999,999 (6 خانات).
- **المظهر**: مغامرة الأعداد تبقى بوضع داكن مهما كان اختيار المظهر (`data-force-theme`)، وباقي الصفحات تتبع الإعداد.
- **نقاط الجلسة**: «نقاط» مغامرة الأعداد تابعة للجلسة فقط؛ النجوم والأوسمة محفوظة دائماً.
- التخطيط متجاوب (جوال/لوحي/حاسوب)، ويُفضّل متصفح حديث. لا إعلانات ولا تتبّع.
